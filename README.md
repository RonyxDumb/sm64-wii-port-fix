# Super Mario 64 Wii / GameCube — Fix Fork

Fork modificato del porting di **Super Mario 64** per Nintendo Wii e GameCube.

L'obiettivo del progetto è mantenere il gioco originale introducendo **miglioramenti, correzioni e funzionalità aggiuntive**, con particolare attenzione alla compatibilità e agli strumenti di sviluppo.

## Miglioramenti

- Supporto e correzioni per gli strumenti di conversione audio **AIFF/AIFC VADPCM**.
- Correzioni e adattamenti agli strumenti di build per **Windows/MSYS2**.
- Miglioramenti specifici per il porting **Wii/GameCube**.
- Struttura del progetto mantenuta compatibile con il sistema di compilazione originale.

## Stato

Il progetto è attualmente **compilabile e funzionante su Wii/GameCube**.

È un fork in sviluppo e possono essere presenti ulteriori problemi o funzionalità ancora da perfezionare.

## Compilazione

Questo fork utilizza lo stesso sistema di compilazione del porting originale.

Per le istruzioni complete relative a:

- installazione degli strumenti necessari;
- configurazione dell'ambiente;
- estrazione degli asset;
- configurazione di Wii/GameCube;
- compilazione del progetto;

consultare la pagina del **porting originale**:

**[Super Mario 64 Wii / GameCube Port](https://github.com/mkst/sm64-port)**

Le istruzioni di compilazione del progetto originale sono applicabili anche a questo fork, salvo eventuali modifiche specificate in questo README.

## Asset

Il repository non distribuisce la ROM originale né gli asset proprietari di Super Mario 64.

Per compilare il progetto è necessaria una copia legalmente ottenuta del gioco originale da cui estrarre gli asset richiesti.
